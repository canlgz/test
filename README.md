# ✦ Conway's Game of Life — Terminal Edition

一個在終端機中運行的康威生命遊戲，有顏色、有動畫、有美感。

## 執行方式

```bash
python3 life.py
```

## 圖案選項

| 選項 | 說明 |
|------|------|
| `random` | 隨機分佈（預設） |
| `glider` | 滑翔機——會在棋盤上移動的小生命 |
| `blinker` | 閃爍者——最簡單的振盪圖案 |
| `pulsar` | 脈衝星——美麗的對稱振盪圖案 |

## 規則

1. 活細胞周圍 **< 2** 個活鄰居 → 死亡（孤獨）
2. 活細胞周圍 **2 或 3** 個活鄰居 → 存活
3. 活細胞周圍 **> 3** 個活鄰居 → 死亡（過擁擠）
4. 死細胞周圍**恰好 3** 個活鄰居 → 誕生

> 按 **Ctrl+C** 退出
